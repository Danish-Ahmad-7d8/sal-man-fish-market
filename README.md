# SAL-MAN Fish Market

Responsive multi-page fish marketplace with:

- Edible Fish marketplace
- Aquarium Fish marketplace
- Separate Seafood Fishmen and Aquarium Stores directory
- Individual seller/business profiles
- Customer cart
- Mobile hamburger navigation
- SAL-MAN brand logo
- Deep sea blue + white + black visual system
- Large non-stretched product photography
- Local CMS at `/admin/` for sellers and products
- Seller and product photo uploads

## Run
Open the folder in VS Code and use Live Server, then open `index.html`.
CMS: `admin/index.html` or `/admin/`.

## Note
The CMS is browser-local for this prototype. For production, connect the CMS to authentication and a shared database so updates are available across devices.
